# embedded-redis documentation

Guides for using and maintaining the library. The `README.md` at the root of the repository is the
short version; everything here goes into more detail.

## Using the library

| Document | What it covers |
|---|---|
| [Getting started](getting-started.md) | Dependency, your first server, lifecycle, ports |
| [Configuration](configuration.md) | `RedisServerBuilder` and `RedisSentinelBuilder` options, generated config files |
| [Executables and binaries](executables.md) | Where the `redis-server` binary comes from and how to supply your own |
| [Clusters](clusters.md) | Sentinel (HA) clusters and sharded clusters |
| [Troubleshooting](troubleshooting.md) | Timeouts, common startup failures, TLS, platform quirks |

## Working on the library

| Document | What it covers |
|---|---|
| [Architecture](architecture.md) | Package layout, process lifecycle, config generation, cluster setup, build and release |

## Other material in this directory

- [`notes.md`](notes.md) — links to the Redis distribution, source and Windows binary releases
- `releases/` — release notes for every published version, generated by `make release-notes`
- `compile/` — Dockerfile and script used by `make build-arm` to compile an ARM Redis binary
- `virusscans/` — VirusTotal scan results for the binaries bundled in the jar
